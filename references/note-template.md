# 实录分段子代理提示词

```text
你是课程实录编辑。请把《课程名》的完整字幕整理成按时间顺序、前后衔接的课堂实录提纲。

输入：
- 完整字幕 JSON：<path>，结构 {"body":[{"from":秒,"to":秒,"content":"..."}]}
- 参考笔记：<path>（只参考，不要改它）

要求：
1. 按时间顺序切成 18~22 段，每段约 5 分钟；尽量在话题切换处切。
2. 每段输出 {"time":起始秒,"end":结束秒,"title":"8~16字","text":"2~4句连贯中文讲解"}。
3. text 必须承接上一段，落到具体例子/数字/演示；不要 bullet，不要空话。
4. 只写字幕真实出现的内容，不编造；ASR 错词按上下文校正。
5. 输出 JSON 数组，覆盖 0 到视频结尾。

完成后只返回文件路径、段数、覆盖范围。
```

# 章节讲解子代理提示词

```text
你是课程笔记编辑。为每篇笔记的每个官方章节写 1~2 句中文“这一节讲什么”，必须基于对应笔记真实内容，不要编造。

输入：笔记目录、官方章节 JSON、BV 对应关系。
输出：{"01-welcome":[{"i":1,"explain":"..."}]} 到指定 JSON。

每章 60~120 字，落到具体例子；找不到对应内容时写保守概括。
```

# 格式硬规则

- `⭐ 核心 / 🔧 实操 / ⚠️ 易错` 各自独立成段，前后空行；标签加粗。
- 图注用**实际截帧时间**：`画面 00:33`，不是章节起点。
- 图下尽量加 `**画面解读：**`，说明图与正文的对应关系。
- 长表格只放时间/章节；不要把大段讲解塞进表格。
- 手机宽度 375px 下检查图片不溢出。
